Llave de GitHub

Se pone una sola vez en cada teléfono o compu. Para sacarla:
  1. Entrá a github.com → nuevo token con la cuenta titularpepe.
  2. Nombre: “Subir videos”. Vencimiento: 90 días (si se pierde un teléfono, la llave deja de servir sola).
  3. En “Repository access” elegí Only select repositories → pepeconductores.
  4. En “Permissions” → “Contents” poné Read and write.
  5. Generalo, copialo y pegalo acá abajo.
